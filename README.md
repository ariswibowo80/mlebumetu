# 💰 Mlebumetu

Aplikasi pencatat keuangan pribadi berbasis PWA — **Keluar Masuk Duit**.

**Live App:** https://ariswibowo80.github.io/mlebumetu/

---

## ✨ Fitur

- **Google Sign-In** + **Demo Mode**
- **Firebase Firestore** — cloud sync otomatis
- **Multi-account** — BCA, GoPay, Payroll, OCBC, dll.
- **Add/Edit/Delete** transaksi
- **Transfer** antar akun
- **CSV Import** — auto-detect + column mapping
- **CSV Export**
- **Category donut chart** (Chart.js)
- **Monthly income vs expense chart**
- **Yearly report**
- **Account contribution pie chart**
- **Speed dial FAB** — Withdrawal / Deposit / Transfer
- **Side menu** navigasi
- **Sync indicator** — ☁ / ↻ / ⚠
- **PWA** — install ke home screen, offline support
